# Resumen

Micro-SaaS que convierte grabaciones de reuniones en tareas, decisiones y correos de seguimiento para un sector concreto.

- `PROMPT.md`: prompt maestro para construir el producto con un agente de código. Incluye la ley de fricción cero, el flujo de usuario, el contrato JSON, el system prompt del motor de IA y un bloque de sector de ejemplo (agencias inmobiliarias) que se puede sustituir por cualquier otro.
